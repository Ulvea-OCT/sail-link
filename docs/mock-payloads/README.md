# Mock payloads

This directory contains fixtures for contract and application development.

## Fixture categories

- `synthetic/`: artificial illustrative data for predictable tests.
- `real-anonymized/`: reserved for real Expedition samples after anonymization and review.

The current synthetic fixture uses clearly marked example identifiers and values. It is not a claim about the actual Expedition metric catalogue.

Real samples have not been supplied in the requirements discussion. Therefore this package does not fabricate or label any fixture as a real Expedition capture.
