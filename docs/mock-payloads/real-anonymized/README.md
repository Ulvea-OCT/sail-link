# Real anonymized Expedition samples

No real Expedition capture was included in the requirements material used to create this package.

Add reviewed samples here only after:
1. capturing a representative Expedition output;
2. removing boat, crew, device, network, location, and other identifying information where present;
3. retaining the original metric identifiers/units needed to validate compatibility;
4. documenting capture context and anonymization review;
5. validating the sample against the current schema.

Do not place credentials, private network details, personal data, or unreviewed raw captures in this directory.
